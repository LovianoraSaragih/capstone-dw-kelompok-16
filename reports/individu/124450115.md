# Laporan perorangan — Rifky Henry Ferdianto (124450115), komponen ekstraksi dan lineage

## 1. Komponen saya
Saya memegang ekstraksi dan lineage: pembaca JSON WebAPI BPS (berpaginasi), CSV BPS sebagai uji
silang, SDMX-CSV ILOSTAT, dan JSON WDI, serta perakitan pipeline Silver–Gold–validasi untuk Sprint 1.
Peran komponen ini adalah memastikan setiap baris Silver dapat ditelusuri ke berkas mentah dan
sha256-nya, dan bahwa empat format sumber dibaca tanpa merusak struktur aslinya.

## 2. Keputusan wrangling
Keputusan utama saya adalah **tidak mengimputasi sel kosong** (K-006). Setelah grid provinsi x tahun
dibentuk, ada 292 sel tanpa observasi (var2011 29, var2016 255, var1254 8). Alternatif yang saya
tolak adalah interpolasi atau mengisi rata-rata provinsi. Alasannya: seri sangat pendek (var1254
hanya 2015–2016), pola missing tidak acak, dan imputasi akan menciptakan nilai yang tidak berasal
dari sumber sehingga memutus lineage. Dampaknya 0 baris ditambah atau dihapus; kekosongan tetap
terlihat di `reports/kelengkapan.csv` dan `reports/grid_bps.csv`. Keputusan satuan (K-002) juga
saya catat karena metadata BPS mengosongkan satuan untuk var2011/var1254; saya set `persen`
berdasarkan definisi indikator dan rentang nilai, bukan menebak dari nama kolom.

## 3. Kegagalan dan pelajaran
Kegagalan nyata: heuristik patahan awal hanya memakai ambang 3×MAD sehingga menandai 70 baris
(semua provinsi pada var2011 2022 dan var2016 air_minum 2023) sebagai kandidat patahan. Setelah
diperiksa, median perubahan tahun itu hanya sekitar 1,1–1,3 poin — terlalu kecil untuk disebut
perubahan definisi/metode. Saya memperbaikinya dengan menambahkan syarat materialitas: median
perubahan absolut minimal 5 poin (K-008). Hasilnya 0 kandidat, dan laporan tidak lagi melebih-lebihkan
patahan. Pelajarannya: kelangkaan statistik bukan bukti patahan struktural; ambang harus punya
arti substantif dan didukung catatan metadata.
